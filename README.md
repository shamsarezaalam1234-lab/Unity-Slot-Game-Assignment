# Unity-Slot-Game-Assignment

Unity Slot Machine Game Assignment

## Overview
This is a Slot Machine game made in Unity. Player can spin the reels and try to match symbols to win coins.

## Features
- Spin Button to spin the reels
- 3 Reels with different symbols
- Win / Lose logic
- Coins / Score System
- Sound Effects
- Simple and Clean UI

## How to Play
1. Press Spin Button
2. Wait for reels to stop
3. If 3 same symbols match - You Win!
4. If symbols do not match - Try Again

## Controls
- Spin Button - Click to Spin
- Bet Button - Increase / Decrease Bet

## Tech Used
- Unity Engine
- C# Scripting
- Unity UI System

## How to Run
1. Open this project in Unity Hub
2. Open Main Scene
3. Press Play Button in Unity Editor

## Project Structure
- Assets / Scripts - Game Logic
- Assets / Scenes - Main Scene
- Assets / Sprites - Symbols and UI Images
- Assets / Audio - Sound Effects
